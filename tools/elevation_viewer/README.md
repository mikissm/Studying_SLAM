# Elevation Lab — 바닥 표면과 통과 가능성 분석

로컬 PCD의 높이별 표면 후보를 분리하고, 하나의 연결된 지면 시트를 선택하는 3D 분석 도구입니다. **바닥이 존재하는 것과 로봇이 통과할 수 있는 것은 서로 다른 레이어입니다.** ROS 빌드는 필요하지 않습니다.

## 실행

워크스페이스 루트에서 실행합니다.

```bash
cd Studying_SLAM
python tools/elevation_viewer/server.py --map /path/to/map.pcd
```

브라우저: http://127.0.0.1:8765 . 다른 포트는 `--port 8766`.
Python 3, NumPy, SciPy가 필요합니다. 저장소 루트에서 `python -m pip install -r tools/elevation_viewer/requirements.txt`로 설치할 수 있습니다. `--map` 없이 실행한 뒤 브라우저에서 파일을 선택해도 됩니다. Three.js 0.170.0과 OrbitControls는 vendor에 포함되어 인터넷 없이 사용할 수 있습니다.

## 기본 사용

1. PCD를 선택합니다. XYZ가 있는 ASCII, binary, binary_compressed 지원. 최대 512MB / 3천만 점.
2. 바닥 표면에서 추출 상태를 확인합니다. 자동 기준 높이가 다른 면을 고르면 수동 기준 높이를 설정합니다.
3. 통과 가능성에서 원본 장애물과 바닥 위 여유 공간을 확인합니다.
4. 보간 영역과 복구 후보는 관측 지면과 구분해서 확인합니다.
5. NPZ 또는 CSV/PCD를 저장합니다. 파라미터 JSON은 다시 불러올 수 있습니다.

좌클릭 드래그 회전, **우클릭 드래그 이동**, 휠 확대. 화면의 위/옆/3D/전체 보기 버튼으로 시점을 바꿀 수 있습니다. 격자를 클릭하면 분류, 좌표, 지지 점 수와 머리 위 여유 공간을 확인합니다. 원본 표시는 최대 30만 점을 균등 샘플링하며 계산은 전체 점을 사용합니다.

## 새 표면 추출 방식 (`layered_surface_v2`)

- XY 셀 안의 점을 높이 간격으로 나눕니다. 바닥·벽·선반·천장이 한 셀에 있어도 하나의 대표 높이로 합치지 않습니다.
- 긴 수직 클러스터는 좁은 높이 밴드와 밀집 높이 피크를 추가 검사합니다. 벽에 접한 바닥이 함께 사라지는 것을 줄입니다.
- 후보의 공분산/법선과 잔차로 수평 또는 허용 경사면인지 평가합니다. 점이 부족한 후보는 약한 후보로 구분합니다.
- 자동 모드는 충분한 지지를 가진 낮은 높이 피크를 기준 지면으로 선택합니다. 수동 모드에서는 지정한 Z 근처의 지면을 선택합니다.
- 후보 그래프는 높이 변화, 경사, 서로의 국소 평면과의 일관성으로 연결됩니다. 같은 XY의 다른 높이로 바로 연결하지 않습니다.
- 약한 후보는 주변 지면에서 복구할 수 있지만, 벽을 타고 위로 확장하는 연결의 중간 지지점으로 사용하지 않습니다. 장애물 점이 있는 표면도 보존하지만 그 점에서 다른 면으로 확장하지 않습니다.
- 결과는 XY당 하나의 선택된 지면입니다. 완전한 다층 PCT 지도나 전복/차체 충돌까지 검증하는 플래너는 아닙니다.

### Z 범위와 장애물 검사의 분리

`zmin/zmax`는 **바닥 후보 높이**만 제한합니다. 좌표 회전 후 원본 전체 점군을 별도로 보존하여 장애물을 검사합니다. 따라서 Z 최댓값을 낮췄다는 이유로 높은 장애물이 검사에서 제거되지 않습니다. 후보 선택 자체가 달라지면 지면과의 상대 높이 및 장애물 결과도 달라질 수 있습니다.

각 지면 높이 위에서 `obstacleheight`보다 높고 `robotheight` 이하인 원본 점이 충분하면 해당 XY를 차단합니다. 바닥과 장애물은 같은 셀에 동시에 존재할 수 있습니다. `wallpadding`은 차단 마스크를 확장하며, 관측된 바닥 높이를 지우지 않습니다. `robotheight`보다 높은 천장은 낮은 통로를 차단하지 않습니다. 여유 공간은 지면 높이에서 시작 높이를 넘는 첫 관측점까지의 차이입니다. 위쪽 점이 없으면 미확인(NaN/null)이며, 무한한 여유가 관측됐다는 뜻이 아닙니다.

### 희소 지면과 보간

`maxgap` 이내의 후보 연결과 단일 패스 Delaunay 보간을 사용합니다. 보간은 지지점 삼각형 내부에서만 수행하고, 최대 변 길이·높이 차이·경사·장애물 장벽을 검사합니다. 관측된 차단 바닥은 보존하지만 보간 지지점으로 사용하지 않습니다. 보간값을 다시 보간 지지점으로 넣어 확장하지 않습니다.

## 저장 형식

- **NPZ**: `elevation[y,x]`는 차단된 바닥을 포함한 선택된 지면 높이입니다. `valid`는 지면 존재, `traversable`은 지면이 있고 차단되지 않은 **통과 후보**, `obstacle`은 독립적인 차단 마스크입니다. `observed`, `recovered`, `interpolated`는 지면 출처를 구분합니다. `clearance`는 관측된 여유 공간이며 미확인은 NaN입니다. `resolution`, `origin_xy`, `metadata_json` 포함.
- **CSV**: `x_m,y_m,z_m,interpolated,recovered,blocked,clearance_m`. 차단된 바닥도 포함하므로 `blocked`를 반드시 함께 읽으세요.
- **PCD**: `x y z interpolated recovered blocked clearance`. 지면 중심점과 동일한 분류 필드.
- **JSON**: 파라미터, 기준 높이, 개수, 좌표계, 분류 정보를 포함합니다.

격자 중심 좌표: `x=origin_xy[0]+(column+0.5)*resolution`, `y=origin_xy[1]+(row+0.5)*resolution`.
회전은 `Ry(pitch) @ Rx(roll) @ source_xyz`. 결과도 이 회전 좌표계로 저장하며 PCD VIEWPOINT는 자동 적용하지 않습니다. 단위 m, Z 위쪽을 가정합니다.

## 한계

자동 지면 선택은 의미론적 인식이 아닙니다. 드문 관측, 노이즈, 서로 가까운 높이의 선반, 실제 단차, 복층 환경에서는 수동 기준 높이와 연결 조건 조정이 필요할 수 있습니다. 관측되지 않은 장애물·구멍을 보간이 덮을 수 있습니다. 원형/사각형 차체 폭, 회전 반경, 바퀴 접촉점, 전복 안정성은 아직 평가하지 않으므로 통과 후보를 실제 주행 안전의 보장으로 사용하면 안 됩니다.

`layered:false`를 명시하면 기존 단일 분위수 방식이 남아 있습니다. 새 UI는 새 방식을 기본으로 사용하며 기존 방식 관련 테스트도 보존되어 있습니다.


동일 셀의 벽+바닥 보존, 천장 분리, 후보 Z 제한과 독립적인 장애물 유지, 수동 지면 선택, 보간 장벽, 파일 형식 및 내보내기 마스크를 검증합니다.

## 원형 로봇 · A* 경로 계획

로봇 패널에서 몸체 반경, 안전 여유, 전체 높이, 몸체 하부 여유, 최대 단차, 최대 경사, 보간/복구 추가 비용을 설정합니다. **통과 판정 갱신 → 출발점/목표점 선택 → 지도 클릭 → A* 경로 찾기** 순서로 사용합니다. '예시 지점'은 가장 큰 통과 후보 연결 영역에서 두 점을 골라 줍니다. 실제 이동 간선의 단차 제한 때문에 예시 지점 사이에도 경로가 없을 수 있습니다.

- 원본 전체 점군에서 새 로봇의 몸체 높이 구간을 검사합니다. 지면 추출 패널의 로봇 높이와 독립적인 계획 설정입니다.
- 빨강은 몸체 충돌, 낮은 상부 간섭 추정, 반경·안전 여유 침범, 국소 경사 초과 또는 미관측 지면 침범입니다. 셀 클릭 시 수치와 사유를 확인합니다. 상부 간섭/몸체 충돌 구분은 반환점의 높이 대역 폭을 이용한 추정입니다.
- 원형 발자국과 장애물 셀의 면적을 고려해 거리장을 확장합니다. '몸체 아래 미관측 지면 차단'을 켜면 지도 경계와 빈 지면으로 발자국이 나가는 것도 차단합니다. 끄더라도 로봇 중심은 확인된 지면 셀에만 위치할 수 있습니다.
- 3×3 주변 지면에 국소 평면을 맞춰 경사를 계산합니다. 몸체 주변의 경사 초과 셀도 피합니다. 단차와 경사 제한을 모두 적용하므로 급격한 작은 턱에서 보수적으로 막힐 수 있습니다.
- A*는 8방향 이동을 사용하고 셀 간 높이 차를 검사합니다. 대각선에서는 두 옆 셀과 그 이동 간선도 확인해 모서리 관통을 차단합니다.
- 비용은 3D 표면 이동 거리 × (1 + 도착 셀 출처별 추가 비용)입니다. 휴리스틱은 목표까지의 3D 직선 거리입니다.
- 경로는 지면 위 노란 선, 출발점은 초록 구, 목표점은 노란 구로 표시합니다. 거리·최대 경사·최대 단차·보간/복구 비율과 탐색 시간을 표시합니다. 경로와 설정은 JSON으로 저장할 수 있습니다.
- 지면/로봇 설정 또는 지점을 바꾸면 이전 경로는 무효화합니다. 지면을 새로 계산하면 출발점과 목표점을 다시 선택하세요.

현재 경로는 정적 단일 지면을 따르는 오프라인 기하학적 검증입니다. 차체 방향·회전 반경·전복·마찰·동적 장애물·실시간 추종은 포함하지 않습니다. 실제 로봇 명령을 발행하지 않습니다.
